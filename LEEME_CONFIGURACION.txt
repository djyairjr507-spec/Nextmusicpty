NEXTMUSICPTY — PROYECTO CON CATÁLOGO COMPARTIDO

ESTA VERSIÓN INCLUYE:
- Página pública conectada a la API /api/mixes.
- Panel privado al hacer doble clic en el logo NEXTMUSICPTY.
- Contraseña validada en el servidor (no está escrita en index.html).
- Catálogo compartido usando Cloudflare D1.
- Portadas guardadas en Cloudflare R2.
- Enlaces externos de descarga; no incluye reproductor integrado.
- Crear, editar y eliminar publicaciones.
- Respaldo JSON para descargar la lista de mixes.
- Las eliminaciones del catálogo NO borran archivos de R2.

IMPORTANTE: conservar los recursos existentes.
No borres el proyecto Pages, la base D1 ni el bucket R2. Este ZIP reemplaza los archivos del código, no el contenido de tu almacenamiento.

CONFIGURACIÓN QUE DEBE EXISTIR EN CLOUDFLARE PAGES (proyecto nextmusicpty):
- D1 binding: variable DB, base de datos nextmusicpty-db.
- R2 binding: variable COVERS, bucket nextmusicpty-mixes.
- Secret ADMIN_PASSWORD: la contraseña que tú elegiste.
- Secret AUTH_SECRET: una clave aleatoria larga (40+ caracteres).
No compartas estos secretos en el chat ni los pongas dentro del HTML.

BASE DE DATOS:
El archivo schema.sql crea la tabla mixes si todavía no existe. Si ya ejecutaste este mismo esquema, no hace falta borrar ni recrear la base de datos. No uses DROP TABLE.

PUBLICACIÓN:
Tu flujo de GitHub Actions publica la rama main en el proyecto Pages nextmusicpty mediante Wrangler. Sube/reemplaza en la raíz del repositorio:
- index.html
- schema.sql
- functions/api/[[path]].js
- .github/workflows/pages-deployment.yml

La carpeta functions es necesaria para que Cloudflare Pages ejecute la API. No la cambies de nombre ni la coloques dentro de otra carpeta.

ADMINISTRADOR:
Abre https://nextmusicpty.pages.dev y haz doble clic en el logo NEXTMUSICPTY. Ingresa tu contraseña. La sesión dura 8 horas.

MIGRACIÓN DE MIXES ANTERIORES:
Los mixes que solo estaban guardados en localStorage de un teléfono no se trasladan automáticamente. Antes de abandonar la versión vieja, descarga el respaldo JSON y conserva tus enlaces y portadas. Luego vuelve a publicar los mixes desde el panel nuevo. Los objetos que ya existan en R2 no se eliminan ni se sobrescriben por este despliegue.

COMPROBACIÓN:
Después del despliegue, abre https://nextmusicpty.pages.dev/api/mixes. Debe mostrar [] si la tabla está vacía, o una lista JSON si ya hay registros. Si aparece un error de bindings, revisa DB y COVERS en Pages > Settings > Functions > Bindings.
